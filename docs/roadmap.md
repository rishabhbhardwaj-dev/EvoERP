# EvoERP — 8 Week Roadmap

## Week 1 — Scope & Design
Deliver:
- requirements.md
- OSS evaluation
- stack decision
- architecture
- ER model
- UI shell/wireframes

## Week 2 — Foundation
- project setup
- PostgreSQL
- authentication
- RBAC
- tenant
- common UI
- audit logging

## Week 3 — Academic Core
- students
- teachers
- classes/sections
- subjects
- student profiles
- attendance

## Week 4 — Finance + Parent
- fees
- invoices
- payments
- receipts
- parent accounts
- parent attendance/fee views

## Week 5 — Exams + Reports
- exams
- marks
- grades
- report card
- basic dashboards
- notices

## Week 6 — Integrations
Evaluate/implement highest-value integrations:
- Moodle
- timetable engine
- analytics
- other approved OSS integrations

## Week 7 — Secondary Modules / Polish
Pick the highest-value approved items:
- HR
- payroll
- inventory
- transport
- library
- enhanced notifications

Do not sacrifice core stability to add features.

## Week 8 — Hardening & Delivery
- integration testing
- security testing
- tenant-isolation testing
- bug fixing
- responsive UI polish
- deployment
- backup/restore validation
- documentation
- demo dataset
- final presentation

## Milestone Rule

At the end of each week there must be a demonstrable increment.
